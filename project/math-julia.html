Watch: Julia Programming Basics

Video & intro by doggo.jl — an excellent source for learning Julia basics and practical coding tips. Highly recommended for beginners!

Lesson Notes

  • Getting Started: Open VS Code, make a new folder, and create a file ending in .jl.
  • Comments: Use # for single-line, #= ... =# for multi-line.
  • Math: 1 + 1, 5 - 2, 3 * 4, 8 / 2, 2 ^ 3, 5 % 2.
  • Whitespace: Julia doesn’t care, but spaces help you read.
  • Order of Operations: PEMDAS, just like math class.

Example Julia Code

# This is a comment
1 + 1
5 - 2
3 * 4
8 / 2
2 ^ 3
5 % 2
#= This is a
multi-line comment =#
(1 + 2) - 3 ^ 4 * 5

Try changing the numbers and see what happens! Julia will show the result right next to your code in VS Code.

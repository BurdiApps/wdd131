Precalculus - Lesson 1: Introduction to Functions

Welcome to the first lesson of Precalculus! Here you'll find notes, resources, and video links for functions, domain, range, and graphing.

Watch: Professor Leonard - Introduction to Functions

Lesson Notes

In this lesson, Professor Leonard covers the basics of functions including definitions, types of functions, and how to graph them. Understanding these concepts is crucial for success in Precalculus and beyond.

Key Concepts:

  • Function Definition: A function is a relation that assigns exactly one output for each input.
  • Domain and Range: The domain is the set of all possible input values, while the range is the set of all possible output values.
  • Graphing Functions: Learn how to plot points and visualize functions on a coordinate plane.

    Lesson Notes

    Hey! Welcome to the first lesson. I’m not a math genius, but here’s what I got from Professor Leonard’s video (he’s also my hero, by the way):

    • What’s a function? It’s just a rule where you put in one number (usually x) and you get out one answer (usually y or f(x)). No weird surprises, just one input, one output. That’s it!
    • Inputs & Outputs: X is what you choose (the “independent variable”), and Y (or f(x)) is what you get (the “dependent variable”).
    • Domain & Range: Domain = all the x’s you’re allowed to use. Range = all the y’s you can get out.
    • Notation: Sometimes you’ll see y = f(x) or g(x) or whatever. It’s just a way to name the function. Don’t stress it.

    Real Life Example

    • Think about a job: you work a certain number of hours (input), you get paid (output). If you work 25 hours, you get one paycheck. If you work 30 hours, you get another. If you work 30 hours and sometimes get two different paychecks… that’s NOT a function (and you should probably talk to your boss!).

    How to Spot a Function

    • If you plug in an x and get more than one answer, it’s NOT a function. Simple as that.
    • If you see a “±” (plus/minus) when solving for y, that usually means it’s not a function—one x gives two y’s. Nope!

    So yeah, that’s the basics. Don’t overthink it. Every input gets one output, and you’re golden. If you want the full, way-better explanation, check out Professor Leonard’s video here.
